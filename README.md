# 🎓 Student Management System (Django + PostgreSQL)

A complete **Student Management System** built using **Django** and **PostgreSQL** as part of my Backend Developer learning journey.

This project demonstrates Django CRUD operations, authentication, authorization, ModelForms, search functionality, and PostgreSQL integration.

* User Authentication (Login / Logout)
* Authorization using Django Permissions
* Add Student
* View All Students
* Search Students
* Update Student

* Clean Django Project Structure

## ▶️ How to Run the Project

### 1. Clone Repository

```bash
git clone https://github.com/Ishantvir/django-learning.git
```

### 2. Create Virtual Environment

```bash
python -m venv venv
```

### 3. Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

### 4. Install Requirements

```bash
pip install -r requirements.txt
```

### 5. Configure PostgreSQL

Update your database settings inside `settings.py`.

### 6. Run Migrations

```bash
python manage.py makemigrations

python manage.py migrate
```

### 7. Start Server

```bash
python manage.py runserver
```
